Personally, I believe that Healthcare data collection is overall a societal benefit, but there has to be strict regulations and limitations in place. HIPPA protects the sharing of personal health data, but it only goes so far. For example, a fitness tracking application may collect health data, and then when that data hits the server, it may send that data to many third-party software API's used to interpret and visualize the data for the fitness tracking application. The problem is that this data is being used in so many places that it is increasing the risk of a data breach, and even if this data is anonomous, it is still possible to link data to other datums and an individuals health data could be at risk.

I believe that there should be more regulations in this space, where software applications are touching personal health data there should be a certain standard of security to be expected in these applications, as well as rules on where they can send and store this personal health data.
