# Description
Chunk templates are going to be used to help me learn how to build software in chunks, leveraging AI to map the destination for me to follow while I build it myself.


# Table Games Management System Specific Prompt
```
I'm building TGMS, a casino table games management system, to learn.
Chunk: <chunk name>. What I build: <...>. Concepts: <...>.
1. Ask me 3-5 questions to find what I already know (don't teach yet).
2. Teach only the gaps, at my level, using TGMS examples.
3. Then guide me through building it. Don't write the code for me;
   give me the next step, review what I type, and ask questions
   when I'm stuck.
4. At the end, give me 5 Anki cards from what I struggled with.
```
