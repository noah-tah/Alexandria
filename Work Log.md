# Social Media Data Collection
- What did I find, and my thoughts about it.
	- Social media collects:
		- Engagement metrics
		- Audience insights
		- Public conversation data
		- Competitive Intelligence
		- Paid performance data
- Do I think that it could provide a societal benefit?
	- Helps refine marketing strategy and content performance
	- Supports real-time market research and customer understanding
	- Enables crisis detection and brand reputation monitoring.
	- Provides insights that connect social activity to business outcomes

- Should an individual be compensated for the use of their data in this instance?
	- I don't think that an individual should be compensated for the use of their data which is used to improve the application. The compensation a user receives is a better user experience when interacting with the app, that is their payment. However, when it comes to data brokers buying and selling this personal data to other companies, this is where users should be compensated, or the social media company should not be allowed to sell this data in the first place.
